# Building the MECHEN H1-Pro kernel from scratch

Target: Linux 3.18.119 for MT6750 (`k50v1_64_bsp`), packaged as a `boot.img` in the exact stock layout.
Host: macOS on Apple Silicon (tested on macOS 14). Linux hosts work with small changes (no `hdiutil`/colima; use any case-sensitive FS and native Docker).

## 1. Prerequisites

```sh
xcode-select --install                  # git
brew install python openssl e2fsprogs docker colima
# Optional (reverse engineering only): Ghidra 12.2 + JDK 25, dtc
```

Disk: ~4 GB source volume (sparse, grows to ~5 GB with objects), ~3 GB Docker image/VM, plus the firmware package.

You also need the **stock firmware package** `T04_50_2_16_4inch_M404_ST7701S_sh1282G003_MECHEN_20260331` (directory or `.zip`). It is not in this repository: it is the vendor's proprietary image.

## 2. One-time setup

```sh
cd kernel
./setup.sh /path/to/T04_50_2_16_4inch_M404_ST7701S_sh1282G003_MECHEN_20260331[.zip]
```

What it does (each step is idempotent):

1. `tools/firmware/extract-stock.sh` → `kernel/stock/`: `boot.img` (header/DTB/signature template), `kernel_image` (stock kernel, input for the generators), `kernel_config` (verified identical to `harness/stock.config`), `vendor_ko/*.ko` (Wi-Fi/BT/FM/GPS modules for the ABI check).
2. Creates `kernel-src.sparseimage` (12 GB sparse, **case-sensitive APFS**) and mounts it at `kernel/src/`. The kernel tree has case-colliding paths, so it must not live on the default case-insensitive volume.
3. Fetches the kernel source at the pinned commit:
   `https://github.com/zhiluan233/android_kernel_cyberfurryrobot_cfb001` @ `a30c78c0f612b29a30f4aeb6e89a39b80b0ea3c3`
   (3.18.119, MT6755, contains `k50v1_64_bsp`; ~93.5% symbol match with stock. Unverified third-party upload: the patches below repair it.)
4. Fetches the **public** AOSP verity test key (`android-9.0.0_r61`) into `harness/keys/` (not committed). The stock boot.img is signed with this key; setup verifies the cert serial `970F983909AA8949`.
5. `harness/prepare-source.sh`: creates branch `mp3-build` = pinned commit + `harness/patches/*.patch` + removal of build artifacts the uploader committed. Then runs the repacker self-test (must print `BYTE-IDENTICAL`).

## 3. Build

```sh
./build.sh                 # → out/boot-<UTC stamp>.img (+ .sha256 .config .version), out/modversions.txt
```

First run builds the Docker image (Ubuntu 18.04 x86_64 + AOSP `aarch64-linux-android-4.9`, the same GCC 4.9 as stock) and starts colima profile `mp3kernel` (`--vm-type vz --vz-rosetta`, 6 CPU / 8 GB / 40 GB). A full build takes ~20–40 min under Rosetta; incremental builds are minutes.

Other commands:

| Command | Purpose |
|---|---|
| `./build.sh selftest` | repack stock kernel → must be byte-identical to stock `boot.img` |
| `./build.sh shell` | shell in the build container (`/src` tree, `/obj` objects, `/out`, `/stock`) |
| `./build.sh reprepare` | rebuild branch `mp3-build` from pinned commit + patches (after editing patches) |
| `KEEP_GOING=1 ./build.sh` | `make -k`: list all errors at once |
| `DTB_MODE=built ./build.sh` | use the tree's DTB instead of the stock one (needs 32-bit DrvGen, which Rosetta can't run: avoid) |

Output naming is a safety gate: `…-UNSAFE-missing-board-drivers.img` (no display/touch, never flash) and `…-WARN-vendor-modules-mismatch.img` (Wi-Fi/BT/FM/GPS modules won't load) are produced when checks fail.

`Error 132` (SIGILL in cc1) is an intermittent Rosetta flake. Just re-run.

## 4. What the build does (`harness/build-in-container.sh`)

1. `.config` = `harness/stock.config` (exact stock IKCONFIG) + `harness/config.fragment` → `olddefconfig`; lost stock options → `out/config-lost.txt`.
2. `make Image.gz` with `LOCALVERSION=` (release string exactly `3.18.119`, required by vendor modules) and `KCFLAGS=-Wno-error=frame-larger-than=`.
3. Appends the **stock DTB** (default), repacks with `harness/mkbootimg.py` (header v1 cloned from stock, new SHA1 id, VB1.0 boot signature with the AOSP test key).
4. `harness/check_modversions.py`: vermagic + every imported symbol CRC of `stock/vendor_ko/*.ko` against vmlinux `__ksymtab`/`__kcrctab`.

## 5. Patches (`harness/patches/`, applied in order)

| # | What | Why |
|---|---|---|
| 0001 | restore `drivers/usb/image` from upstream 3.18.119 | dropped by uploader's `.gitignore` (`Image`) on a case-insensitive FS |
| 0002 | restore 12 lowercase netfilter files from upstream | lost to case collisions |
| 0003 | `proc_info.o` frame-size warning non-fatal | stock builds it |
| 0004 | flashlight: drop rt5081 `flashlight_device` | not on this board, source absent |
| 0005 | LCM drivers `st7701boe` + `nv3049f` | regenerated byte-exact from stock (`tools/gen_lcm.py`) |
| 0006 | stock single-profile battery tables | `tools/gen_battery.py`; multi-profile code in tree doesn't even compile |
| 0007 | weak OTG/charger stubs, build stock `leds_strobe` flashlight | MECHEN uses the MT6353 linear charger |
| 0008 | `rtc_time.tm_cnt` (+36-byte ioctl numbers), 2-callback `wmt_platform_bridge` | stock ABI for vendor modules |
| 0009 | `__dynamic_pr_debug` exported with stock CRC | ABI verified identical; genksyms text differs |
| 0010 | `wmt_export_platform_bridge_register` exported with stock CRC | same |
| 0011 | exFAT 1.2.9 (`dorimanx/exfat-nofuse` 01c30ad5) built in | exact stock version |
| 0012 | side keys prev/next/contacts (EINT) in `kpd.c` | recovered from stock |
| 0013 | Hynitron CST3XX touch, clean-room (`tools/cst3xx_mp3.c`) | stock behaviour, **no firmware-update path** |

Editing workflow: `git -C src/linux checkout -B patchwork mp3-build~1` (i.e. before the artifact-removal commit), change + commit, `git format-patch -1 --start-number N -o ../../harness/patches`, then `./build.sh reprepare`.

## 6. Regenerating recovered data

```sh
python3 tools/gen_lcm.py     stock/kernel_image src/linux/drivers/misc/mediatek/lcm
python3 tools/gen_battery.py stock/kernel_image src/linux
```

Addresses are stock-kernel virtual addresses; **load base is `0xffffffc000080000`** (Image header text_offset 0x80000), not the `_stext`-guessed `0xffffffc000082000`.

## 7. Reverse-engineering setup (optional)

```sh
vmlinux-to-elf --base-address ffffffc000080000 stock/kernel_image kernel.elf     # pip install vmlinux-to-elf
ghidra_12.2_PUBLIC/support/analyzeHeadless <projdir> KernelRE -import kernel.elf \
    -scriptPath tools/ghidra -preScript NoNoReturnDiscovery.java \
    -postScript DecompileAll.java <outdir> '<name regex>'
```

`NoNoReturnDiscovery.java` is required: otherwise Ghidra marks `printk` noreturn and truncates every function at its first log line. ABI probe helpers (genksyms CRC experiments) are in `tools/abi/` (run inside `./build.sh shell` with `tools/abi` mounted).
